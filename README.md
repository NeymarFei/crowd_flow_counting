# crowd_flow_counting
Video Pedestrian Flow Counting for Metro
# 数据集标注说明
密集视频行人流量计数 | 课程设计

## 基本信息
- **项目名称**：crowd_flow_counting
- **数据场景**：地铁监控密集人群视频
- **标注工具**：X-AnyLabeling
- **总标注帧数**：590 帧
- **标注格式**：人头中心点标注 + 动态 Mask 区域

## 标签定义
- `inflow`：上一帧不存在，当前帧新进入
- `outflow`：当前帧存在，下一帧离开
- `both`：仅在当前帧出现
- `pedestrian`：连续三帧均存在
- `mask`：模糊、过暗、遮挡区域（矩形标注）

## 标注规则
- 按 **2 秒间隔** 抽取视频帧
- 人头点标注于**头部几何中心**
- `mask` 区域**逐帧动态标注**，不强制统一
- 第一帧仅允许：`outflow` / `pedestrian`
- 最后一帧仅允许：`inflow` / `pedestrian`

## 文件格式
- 图片：视频抽帧图（本地存储）
- 标注：JSON 格式（X-AnyLabeling 自动生成）
- 存储：**仅本地/小组内部保存，不上传 GitHub**

## 注意事项
原始视频、标注图片、JSON 文件**严禁公开、外传、上传至任何公开平台**，仅用于课程设计模型训练与测试。
