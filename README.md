# crowd_flow_counting
Video Pedestrian Flow Counting for Metro

# 数据集标注说明
**密集视频行人流量计数 | 课程设计**

## 基本信息
- **项目名称**：crowd_flow_counting
- **数据场景**：武汉地铁监控密集人群视频
- **标注工具**：X-AnyLabeling
- **总标注帧数**：590 帧（截至5.17）
- **标注格式**：人头中心点标注 + 动态 Mask 区域

## 标签定义
- `inflow`：上一帧不存在，当前帧新进入（如从画面边缘进入）。
- `outflow`：当前帧存在，下一帧离开（如走出画面或过线）。
- `both`：仅在当前帧出现（极短时间出现的噪声或快速移动个体）。
- `pedestrian`：连续三帧均存在（稳定的跟踪目标）。
- `mask`：模糊、过暗、遮挡区域（使用矩形标注，用于屏蔽无效计算）。

## 标注规则
1. **抽帧逻辑**：按 **2 秒间隔** 抽取视频帧，保证动作的连续性与标注量平衡。
2. **位置标准**：人头点标注于 **头部几何中心**。
3. **动态掩码**：`mask` 区域 **逐帧动态标注**，随人群拥挤程度调整，不强制统一。
4. **边界逻辑**：
   - 第一帧仅允许标签：`outflow` / `pedestrian`。
   - 最后一帧仅允许标签：`inflow` / `pedestrian`。

## 文件格式与安全
- **图片**：视频抽帧图（本地存储）。
- **标注**：JSON 格式（X-AnyLabeling 自动生成）。
- **存储政策**：**严禁公开、外传、上传至任何公开平台（包括 GitHub）**。标注数据仅供小组内部模型训练使用。
